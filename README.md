## Drag-and-Drop Interaction Updates

- **Targeting an Item (Card)**:
  - When you click and drag an item, **only that item receives the dashed outline**. The whole category does not get the green outline.
  - You can still drag the item vertically across categories to move the category up or down, or drag within the category to reorder cards horizontally and vertically.
- **Targeting a Category**:
  - When you click and drag a category header directly, the **whole category receives the green dashed outline** (`outline: 2px dashed var(--accent-color)`), and dragging vertically moves the entire category up or down.

The standalone vanilla single-file code is also available in `/public/vanilla-index.html` for direct deployment to GitHub Pages.
